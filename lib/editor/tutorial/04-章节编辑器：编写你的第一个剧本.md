## 章节编辑器界面认识

### 编辑区域
章节编辑器位于软件的中央区域，包含：
- **文本编辑框**: 主要的剧本编写区域
- **工具栏**: 各种格式化和编辑工具
- **行号显示**: 帮助定位和调试
- **语法高亮**: 不同类型的内容用不同颜色显示

### 工具栏功能
- **撤销/重做**: 快捷键 Ctrl+Z / Ctrl+Y
- **查找替换**: 快捷键 Ctrl+F
- **全屏模式**: 专注编写的全屏界面
- **字数统计**: 实时显示字数信息

## 剧本基本格式

### 对话格式
```
角色名: 对话内容

示例：
小明: 你好，很高兴见到你！
艾莉丝: 我也很高兴见到你。
```

### 旁白格式
```
[旁白内容]

示例：
[太阳缓缓西下，校园里传来阵阵鸟鸣声。]
[小明走到了教学楼前，心情有些紧张。]
```

### 选择分支格式
```
[选择]
1. 选择项一
2. 选择项二
3. 选择项三

示例：
[选择]
1. 向前走进教室
2. 在走廊里继续等待
3. 转身离开
```

### 场景描述
```
[场景: 场景名称]

示例：
[场景: 学校走廊]
[场景: 图书馆]
```

## 编写第一个章节

### 1. 创建新章节
1. 在左侧章节列表中点击"添加章节"
2. 输入章节标题，如"第一章：相遇"
3. 系统会创建新的章节文件并打开编辑器

### 2. 编写开场
让我们创建一个简单的开场：

```
[场景: 樱花飞舞的校园]

[春天的校园里，樱花瓣随风飘舞。这是开学的第一天，空气中弥漫着新鲜感和未知的期待。]

主角: （今天是新学期的开始，希望能交到新朋友。）

[主角走在通往教学楼的小径上，突然一阵风吹过，樱花瓣落在了肩膀上。]

艾莉丝: 等一下！

[一个声音从后面传来，主角回头看去。]

艾莉丝: 你肩膀上有樱花瓣。

主角: 谢谢你提醒我。

艾莉丝: 不客气，我是艾莉丝，很高兴认识你。

主角: 我也很高兴认识你，我是...

[选择]
1. 热情地介绍自己
2. 害羞地简单回应
3. 开个小玩笑
```

### 3. 保存章节
编写完成后记得保存：
- 使用快捷键 Ctrl+S
- 或者点击工具栏的"保存"按钮
- 系统会自动保存到项目的 chapters 文件夹中

## 剧本编写技巧

### 对话编写要点
1. **自然流畅**: 对话应该像真人对话一样自然
2. **符合角色**: 每个角色的说话方式要保持一致
3. **推进剧情**: 对话要为故事发展服务
4. **有节奏感**: 适当的停顿和语气变化

### 旁白编写技巧
1. **营造氛围**: 用环境描述营造场景氛围
2. **描述动作**: 描述角色的行为和表情
3. **内心独白**: 表达角色的内心想法
4. **简洁有力**: 避免过长的描述段落

### 选择设计原则
1. **有意义的选择**: 每个选择都应该产生不同结果
2. **符合情境**: 选择内容要符合当前场景
3. **平衡性**: 各个选择的吸引力要相对平衡
4. **数量适中**: 一般 2-4 个选择比较合适

## 实战练习

### 练习1：基础对话
编写一段包含两个角色的对话，内容是初次见面的自我介绍。

### 练习2：场景描述
用旁白描述一个具体的场景，比如教室、公园或咖啡厅。

### 练习3：选择分支
为上面的对话添加一个选择点，让玩家可以选择不同的回应方式。

### 练习4：完整章节
结合前面的练习，创建一个完整的短章节，包含开场、发展和结尾。

## 常见问题解答

**Q: 为什么我的角色名不会高亮显示？**
A: 确保角色名后面有冒号，并且该角色已在角色管理中创建。

**Q: 如何在对话中表示停顿？**
A: 可以使用省略号(...)或者在旁白中描述停顿。

**Q: 选择分支可以跳转到不同章节吗？**
A: 可以，后面的章节会详细介绍跳转设置。

**Q: 编辑器支持导入其他格式的文本吗？**
A: 支持导入纯文本(.txt)文件，但需要手动调整格式。

**Q: 如何备份我的剧本？**
A: 定期保存项目，或者使用项目导出功能创建备份。
