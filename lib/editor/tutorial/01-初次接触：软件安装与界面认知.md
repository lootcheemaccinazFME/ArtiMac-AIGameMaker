# 01-初次接触：软件安装与界面认知

## 本章你将学会
- 如何下载和安装 ArtiMeow AI GalGame Maker
- 认识软件的主界面和各个功能区域
- 了解什么是 GalGame（视觉小说）

## 什么是 GalGame？
GalGame（Gal Game）也叫视觉小说，是一种以故事剧情为主的互动式电子游戏。玩家通过阅读文字、观看图片，并在关键时刻做出选择来推进剧情。著名的作品有《CLANNAD》、《命运石之门》等。

## 软件安装步骤

### 1. 系统要求
- 操作系统：Windows 10/11、macOS 10.14+ 或 Linux
- 内存：至少 4GB RAM（推荐 8GB+）
- 硬盘空间：至少 2GB 可用空间
- 网络连接：用于 AI 功能的在线服务

### 2. 下载软件
1. 访问官方网站或 GitHub 发布页面
2. 选择适合你操作系统的安装包
3. 下载完成后运行安装程序
4. 按照安装向导完成安装

### 3. 首次启动
1. 双击桌面上的 ArtiMeow 图标
2. 首次启动会显示欢迎界面
3. 软件可能会请求网络访问权限（用于 AI 功能）
4. 等待软件完全加载

## 主界面认识

### 左侧面板：项目导航区
- **项目列表**：显示你创建的所有游戏项目
- **章节列表**：当前项目的所有章节
- **资源库**：图片、音频等素材管理

### 中央区域：编辑工作区
- **章节编辑器**：编写游戏剧本的主要区域
- **时间线视图**：可视化显示章节流程
- **预览窗口**：实时预览游戏效果

### 右侧面板：功能区
- **角色管理**：创建和编辑游戏角色
- **AI 助手**：智能续写和生成功能
- **项目设置**：游戏基本信息配置

### 顶部工具栏
- **文件操作**：新建、打开、保存项目
- **编辑工具**：撤销、重做、查找替换
- **预览工具**：运行游戏、打包发布

## 界面主题设置
ArtiMeow 提供了多种界面主题：
1. 点击右上角的设置按钮（齿轮图标）
2. 选择"界面主题"
3. 可选择浅色、深色或跟随系统主题

## 常见问题解答

**Q: 软件启动很慢是正常的吗？**
A: 首次启动会比较慢，因为需要初始化各种组件。后续启动会变快。

**Q: 可以离线使用吗？**
A: 基本的编辑功能可以离线使用，但 AI 辅助功能需要网络连接。

**Q: 支持哪些语言？**
A: 目前主要支持中文，未来会添加更多语言支持。

## 小练习
1. 启动软件并熟悉各个区域的位置
2. 尝试切换不同的界面主题
3. 点击各个按钮，观察会发生什么（不用担心弄坏什么）
