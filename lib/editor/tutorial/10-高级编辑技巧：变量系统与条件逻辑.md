## 变量系统概述

变量系统让你的游戏更加智能和个性化：
- **记录玩家选择**: 跟踪玩家的决定和偏好
- **角色关系**: 管理角色间的好感度和关系状态
- **游戏进度**: 记录完成的任务和解锁的内容
- **个性化体验**: 根据变量值显示不同内容

## 变量的基本概念

### 变量类型
- **数字变量**: 存储数值，如好感度、分数等
- **文本变量**: 存储文字，如玩家姓名、选择记录
- **布尔变量**: 存储真/假状态，如是否完成某个事件

### 变量作用域
- **全局变量**: 在整个游戏中都有效
- **章节变量**: 只在特定章节中有效
- **临时变量**: 仅在当前场景中使用

## 创建和使用变量

### 1. 变量定义语法
```
[设置变量: 变量名 = 值]

示例：
[设置变量: 好感度_艾莉丝 = 0]
[设置变量: 玩家姓名 = "小明"]
[设置变量: 已完成教程 = false]
```

### 2. 修改变量值
```
[设置变量: 好感度_艾莉丝 = 好感度_艾莉丝 + 1]
[设置变量: 玩家姓名 = "新名字"]
[设置变量: 已完成教程 = true]
```

### 3. 在文本中显示变量
```
艾莉丝: 你好，{玩家姓名}！
旁白: [当前好感度：{好感度_艾莉丝}]
```

## 条件判断系统

### 1. 基本条件语法
```
[如果: 条件]
    执行内容
[否则]
    备选内容
[结束]
```

### 2. 条件判断示例
```
[如果: 好感度_艾莉丝 >= 50]
    艾莉丝: 我很开心能和你成为好朋友！
[否则]
    艾莉丝: 嗯...我们还不算太熟悉。
[结束]
```

### 3. 复杂条件
```
[如果: 好感度_艾莉丝 >= 50 且 已完成教程 = true]
    艾莉丝: 看来你已经很熟悉这里了！
[否则如果: 好感度_艾莉丝 >= 30]
    艾莉丝: 你学得很快呢。
[否则]
    艾莉丝: 需要我帮你熟悉一下环境吗？
[结束]
```

## 高级应用场景

### 1. 好感度系统
```
# 初始化角色好感度
[设置变量: 好感度_艾莉丝 = 0]
[设置变量: 好感度_小明 = 0]

# 在选择中影响好感度
[选择]
1. 温和地回应 → [设置变量: 好感度_艾莉丝 = 好感度_艾莉丝 + 2]
2. 开个玩笑 → [设置变量: 好感度_小明 = 好感度_小明 + 1]
3. 保持沉默 → [设置变量: 好感度_艾莉丝 = 好感度_艾莉丝 - 1]

# 根据好感度显示不同结局
[如果: 好感度_艾莉丝 >= 80]
    跳转到: 艾莉丝好结局
[否则如果: 好感度_小明 >= 80]
    跳转到: 小明好结局
[否则]
    跳转到: 普通结局
[结束]
```

### 2. 成就系统
```
# 定义成就变量
[设置变量: 成就_完美主义者 = false]
[设置变量: 成就_探索家 = false]

# 检查成就条件
[如果: 好感度_艾莉丝 >= 100 且 好感度_小明 >= 100]
    [设置变量: 成就_完美主义者 = true]
    [显示通知: 获得成就：完美主义者]
[结束]
```

### 3. 分支记忆系统
```
# 记录重要选择
[设置变量: 选择_帮助艾莉丝 = true]

# 在后续章节中引用
[如果: 选择_帮助艾莉丝 = true]
    艾莉丝: 谢谢你那天帮助我，我一直记得。
[否则]
    艾莉丝: 你好像变了一些...
[结束]
```

### 2. 变量修改
调试时可以：
- 手动修改变量值
- 测试不同的条件分支
- 验证逻辑是否正确

### 3. 变量日志
系统会记录：
- 变量的创建和修改时间
- 变量值的变化历史
- 条件判断的执行结果

## 最佳实践

### 1. 变量命名规范
- 使用描述性的名称：`好感度_艾莉丝` 而非 `a1`
- 区分不同类型：`计数器_对话次数`、`标志_已见面`
- 使用一致的命名风格

### 2. 避免常见错误
- 确保变量在使用前已定义
- 注意变量名的大小写敏感
- 检查条件判断的逻辑正确性

### 3. 性能优化
- 避免创建过多不必要的变量
- 及时清理临时变量
- 使用合适的变量作用域

## 常见问题解答

**Q: 变量值在游戏重新开始后会保留吗？**
A: 不会，每次新游戏都会重新初始化变量。

**Q: 可以在一个表达式中使用多个变量吗？**
A: 可以，支持数学运算和逻辑运算。

**Q: 变量系统会影响游戏性能吗？**
A: 正常使用不会，但避免在循环中频繁操作变量。

**Q: 如何实现变量的持久化存储？**
A: 使用游戏的存档系统，变量会随存档一起保存。

**Q: 变量名可以使用中文吗？**
A: 可以，但建议使用英文或拼音避免编码问题。

## 高级功能

### 1. 数组变量
```
[设置变量: 角色列表 = ["艾莉丝", "小明", "小红"]]
[设置变量: 好感度列表 = [50, 30, 70]]
```

### 2. 函数式操作
```
[设置变量: 总好感度 = 求和(好感度列表)]
[设置变量: 最喜欢角色 = 最大值索引(好感度列表)]
```

### 3. 事件触发器
```
[当变量改变: 好感度_艾莉丝]
    [如果: 好感度_艾莉丝 = 50]
        [触发事件: 艾莉丝表白]
    [结束]
[结束]
```
