## 创建自定义主题

### 1. 主题文件结构
```css
/* 自定义主题示例 */
.game-theme-custom {
  --primary-color: #4a90e2;
  --secondary-color: #f5f5f5;
  --text-color: #333333;
  --accent-color: #e74c3c;
}

.dialogue-box {
  background: var(--secondary-color);
  border: 2px solid var(--primary-color);
  color: var(--text-color);
}
```

### 2. 应用自定义主题
1. 创建主题CSS文件
2. 在项目设置中导入主题
3. 在游戏中激活主题
4. 预览和调整效果
