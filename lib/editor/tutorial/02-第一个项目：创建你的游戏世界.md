# 02-第一个项目：创建你的游戏世界

- 如何创建新的 GalGame 项目
- 项目设置的各个选项含义
- 项目文件结构的基本认识
- 如何设置项目的基本信息

## 创建新项目

### 1. 启动项目创建向导
1. 打开 ArtiMeow 软件
2. 点击左上角的"新建项目"按钮，或使用快捷键 `Ctrl+N`
3. 系统会弹出"新建项目"对话框

### 2. 填写项目基本信息
在对话框中你需要填写：

**项目名称**
- 输入你游戏的名字，比如"我的第一个游戏"
- 项目名称会显示在游戏启动时
- 可以使用中文、英文和数字

**项目描述**
- 简短描述你的游戏内容
- 比如"一个关于友情与成长的校园故事"
- 这个描述会帮助你记住项目内容

**作者**
- 填入你的名字或笔名
- 会显示在游戏的制作者信息中

**游戏类型**
- 恋爱：以爱情故事为主题
- 冒险：探索和解谜类型
- 悬疑：推理和悬疑剧情
- 校园：学校生活背景
- 奇幻：魔法和幻想世界
- 其他：自定义类型

### 3. 选择项目位置
1. 点击"浏览"按钮选择项目保存位置
2. 建议在文档文件夹下创建"我的游戏项目"文件夹
3. 确保选择的位置有足够的存储空间

### 4. 完成创建
点击"创建项目"按钮，系统会：
1. 在指定位置创建项目文件夹
2. 自动生成必要的配置文件
3. 打开新项目的编辑界面

## 认识项目文件结构

创建完成后，你的项目文件夹会包含：

```
我的第一个游戏/
├── project.json        # 项目配置文件
├── chapters/           # 章节文件夹
├── characters/         # 角色信息文件夹
├── assets/            # 素材资源文件夹
│   ├── images/        # 图片素材
│   ├── audio/         # 音频素材
│   └── music/         # 背景音乐
└── build/             # 打包输出文件夹
```

### 各文件夹作用说明
- **project.json**: 存储游戏的基本设置和配置
- **chapters/**: 存储所有章节的剧本和内容
- **characters/**: 存储角色的设定和信息
- **assets/**: 存储游戏用到的图片、音频等素材
- **build/**: 项目打包后的输出文件会存放在这里

## 项目设置详解

### 基本信息设置
在左侧面板点击"项目设置"可以修改：
- **游戏标题**: 显示在游戏窗口标题栏
- **版本号**: 用于跟踪游戏版本，格式如"1.0.0"
- **发布日期**: 游戏的发布时间
- **官网地址**: 你的个人网站或游戏主页

### 游戏显示设置
- **窗口大小**: 设置游戏运行时的窗口尺寸
  - 1280x720（推荐，适合大多数屏幕）
  - 1920x1080（高清画质）
  - 800x600（经典尺寸）
- **全屏模式**: 是否允许玩家使用全屏模式
- **窗口缩放**: 是否允许玩家调整窗口大小

### 文本显示设置
- **默认字体**: 选择游戏中显示文字的字体
- **字体大小**: 设置文字的默认大小
- **文字颜色**: 设置对话文字的颜色
- **背景透明度**: 设置文字框背景的透明程度

## 项目管理技巧

### 项目备份
定期备份你的项目非常重要：
1. 在项目列表中右击项目名称
2. 选择"导出项目"
3. 选择备份保存位置
4. 系统会创建包含所有文件的压缩包

### 项目重命名
如果需要修改项目名称：
1. 在项目设置中修改"项目名称"
2. 点击"保存设置"
3. 项目列表中的名称会自动更新

### 项目删除
**注意：删除操作不可恢复，请谨慎操作**
1. 在项目列表中右击项目
2. 选择"删除项目"
3. 确认删除操作

## 常见问题解答

**Q: 创建项目时提示路径无效？**
A: 检查路径中是否包含特殊字符，建议使用纯英文路径。

**Q: 项目文件可以随意移动吗？**
A: 不建议直接移动项目文件夹，应该通过软件的"导出/导入"功能。

**Q: 误删了项目怎么办？**
A: 可以尝试在回收站恢复，或者使用之前的备份文件。

**Q: 可以同时打开多个项目吗？**
A: 目前只支持同时编辑一个项目，但可以在项目列表中快速切换。
