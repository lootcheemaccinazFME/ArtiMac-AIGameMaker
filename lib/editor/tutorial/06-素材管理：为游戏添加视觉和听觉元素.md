# 06-素材管理：为游戏添加视觉和听觉元素

## 本章你将学会
- 如何添加和管理游戏素材
- 背景图片的使用方法
- 音效和背景音乐的设置
- 角色立绘的管理技巧

## 素材系统概述

GalGame 的魅力很大程度来自于丰富的视觉和听觉体验。ArtiMeow 提供了完善的素材管理系统，支持：
- **图片素材**: 背景图、角色立绘、CG图片
- **音频素材**: 背景音乐、音效、语音
- **其他资源**: 字体文件、特效资源

## 访问素材管理

### 1. 打开资源库
1. 在左侧导航面板找到"资源库"选项卡
2. 点击进入素材管理界面
3. 你会看到按类型分类的素材列表

### 2. 素材分类说明
- **背景图片**: 游戏场景的背景图像
- **角色立绘**: 角色的全身图像，包含不同表情和姿势
- **CG图片**: 特殊剧情的插图
- **背景音乐**: 循环播放的背景音乐
- **音效**: 短暂的效果音
- **语音**: 角色对话的语音文件

## 添加图片素材

### 1. 添加背景图片
1. 在资源库中选择"背景图片"分类
2. 点击"添加素材"按钮
3. 从电脑中选择图片文件
4. 系统会自动复制文件到项目文件夹

### 2. 图片格式要求
**推荐格式**
- PNG: 支持透明背景，质量最佳
- JPG: 文件较小，适合背景图
- 不推荐 BMP 或 GIF 格式

**尺寸建议**
- 背景图片: 1920x1080 或 1280x720
- 角色立绘: 400x800 到 600x1200
- CG图片: 根据用途决定，通常与游戏分辨率一致

### 3. 图片预览和编辑
- 点击图片可以查看大图预览
- 支持基本的图片信息查看（尺寸、大小等）
- 可以为图片添加标签和描述

## 设置背景图片

### 1. 为章节设置背景
1. 打开要设置背景的章节
2. 在章节开头添加场景标记：
   ```
   [场景: 教室]
   ```
3. 在右侧的章节属性面板中选择对应的背景图片

### 2. 背景切换效果
可以设置背景切换时的过渡效果：
- 淡入淡出（推荐）
- 滑动切换
- 立即切换
- 自定义动画

### 3. 动态背景设置
对于某些特殊场景，可以设置动态背景：
- 设置多张背景图片的切换序列
- 调整切换时间间隔
- 设置是否循环播放

## 角色立绘管理

### 1. 添加角色立绘
1. 在角色管理界面选择对应角色
2. 点击"添加立绘"按钮
3. 选择立绘图片文件
4. 设置立绘的显示名称（如"默认"、"高兴"、"生气"等）

### 2. 立绘使用技巧
**命名规范**
- 使用清晰的名称，如"小明_默认"、"小明_微笑"
- 统一命名格式便于管理
- 避免使用特殊字符

**立绘设计要点**
- 保持角色比例一致
- 确保立绘风格统一
- 准备足够的表情变化

### 3. 在剧本中使用立绘
在章节编辑器中，可以通过特殊标记设置立绘：
```
[显示: 小明_微笑]
小明: 很高兴见到你！

[隐藏: 小明]
[旁白内容...]

[显示: 艾莉丝_惊讶]
艾莉丝: 真的吗？
```

## 音频素材管理

### 1. 添加背景音乐
1. 在资源库中选择"背景音乐"分类
2. 点击"添加素材"按钮
3. 选择音频文件（支持 MP3、WAV、OGG 格式）
4. 为音乐设置名称和标签

### 2. 音频格式建议
- **MP3**: 文件小，兼容性好，推荐使用
- **WAV**: 质量高但文件大，适合重要音乐
- **OGG**: 开源格式，质量与 MP3 相当

### 3. 设置背景音乐
在章节中设置背景音乐：
```
[音乐: 轻松愉快的校园音乐]
[旁白内容...]

[音乐: 停止]
[切换到无背景音乐状态...]

[音乐: 紧张的音乐]
[紧张场景的内容...]
```

## 音效和语音

### 1. 添加音效
1. 在"音效"分类中添加短音频文件
2. 音效通常用于：
   - 按钮点击声
   - 门铃、电话铃声
   - 脚步声、风声等环境音

### 2. 在剧本中使用音效
```
[音效: 门铃声]
[门铃响起，有人来访。]

小明: 我去开门。

[音效: 开门声]
```

### 3. 语音系统（可选）
如果有语音资源：
1. 为每个角色创建语音文件夹
2. 按章节或对话编号命名语音文件
3. 在角色设置中关联语音文件

## 素材组织和管理

### 1. 文件夹组织
建议在项目的 assets 文件夹中创建清晰的目录结构：
```
assets/
├── images/
│   ├── backgrounds/     # 背景图片
│   ├── characters/      # 角色立绘
│   └── cg/             # CG图片
├── audio/
│   ├── music/          # 背景音乐
│   ├── sounds/         # 音效
│   └── voice/          # 语音文件
└── fonts/              # 字体文件
```

### 2. 命名规范
- 使用英文或拼音命名文件
- 避免空格和特殊字符
- 使用有意义的名称
- 保持命名风格一致

### 3. 素材备份
定期备份素材文件：
1. 将原始素材保存在项目文件夹外
2. 定期导出项目包含所有素材
3. 使用版本控制系统管理变更

## 实战练习

### 练习1：添加背景
1. 为你的项目添加3-5张不同场景的背景图片
2. 在不同章节中使用这些背景
3. 测试背景切换效果

### 练习2：角色立绘
1. 为主要角色添加至少3种不同表情的立绘
2. 在对话中根据情境切换立绘
3. 观察立绘显示效果

### 练习3：音乐和音效
1. 添加2-3首背景音乐
2. 在不同章节中使用不同的音乐
3. 添加一些简单的音效

## 常见问题解答

**Q: 图片文件很大，会影响游戏性能吗？**
A: 会的，建议优化图片大小。背景图不超过2MB，立绘不超过1MB。

**Q: 支持动态图片（GIF）吗？**
A: 目前不直接支持GIF，但可以通过连续切换图片实现动画效果。

**Q: 音频文件应该用什么音质？**
A: 背景音乐建议128-192kbps的MP3，音效可以用更低的比特率。

**Q: 可以使用网络上的图片和音乐吗？**
A: 建议使用原创或正版授权的素材，避免版权问题。

**Q: 素材文件丢失了怎么办？**
A: 从备份恢复，或者在素材管理中重新关联文件。

## 优化建议

### 文件大小优化
1. 压缩图片但保持质量
2. 选择合适的音频比特率
3. 删除不使用的素材文件

### 加载速度优化
1. 预加载常用素材
2. 按需加载大型文件
3. 使用适当的文件格式
