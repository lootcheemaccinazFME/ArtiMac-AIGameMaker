## 故事结构设计技巧

### 线性结构
最简单的结构，章节按顺序连接：
```
开始 → 第一章 → 第二章 → 第三章 → 结局
```

### 分支结构
在关键点让玩家做选择，产生不同的故事分支：
```
开始 → 第一章 → [选择点]
                    ├→ 路线A → 结局A
                    ├→ 路线B → 结局B
                    └→ 路线C → 结局C
```

### 汇聚结构
不同分支最终汇聚到同一点：
```
开始 → [选择点]
        ├→ 路线A ─┐
        └→ 路线B ─┴→ 汇聚点 → 结局
```

### 树状结构
复杂的多层分支：
```
开始 → [选择1]
        ├→ 路线A → [选择2]
        │          ├→ 结局A1
        │          └→ 结局A2
        └→ 路线B → 结局B
```

## 实战练习

### 练习1：简单分支
1. 创建一个包含选择的章节
2. 创建两个不同的后续章节
3. 将选择连接到这两个章节
4. 在时间线中查看结果

### 练习2：复杂路径
1. 设计一个三层分支的故事结构
2. 第一层有2个选择
3. 每个选择后又有2个子选择
4. 总共创建6个不同的结局

### 练习3：路径检查
1. 使用时间线的路径跟踪功能
2. 从开始到每个结局走一遍
3. 确保没有断开的连接
4. 检查是否存在死路

## 常见问题解答

**Q: 可以创建循环的故事结构吗？**
A: 可以，但要小心避免无限循环，建议添加退出条件。
